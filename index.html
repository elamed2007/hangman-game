What is the game Hangman?

It is a game where a player has to guess a word letter by letter.
    With each incorrect letter, a part of a man is drawn (the gallows, the head, the body...).
    If the drawing is complete before the word is found → the player loses.
    If the player finds all the letters → he wins.
